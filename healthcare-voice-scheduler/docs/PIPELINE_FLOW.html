Healthcare Voice Scheduler — Phase 1

One phone call, traced end to end

Every stage between a caller's voice and a booked appointment sits behind a fixed interface — VoiceChannel, AgentOrchestrator, SchedulingBackend. The dialogue agent is already real (Claude Sonnet 5, native tool-calling); the phone audio and the scheduling data are still mocked, so the full path below runs with just an ANTHROPIC_API_KEY — no Twilio/Deepgram/NPPES/FHIR accounts needed yet. The shape doesn't change when those replace the remaining mocks — only what's behind each box does.
